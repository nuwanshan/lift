# Lift

An 8-month strength plan (2 Nov 2026 – 18 Jun 2027) as an offline phone app. Two plans share one app:

- Nuwan: https://nuwanshan.github.io/lift/ (Android: Chrome → Install app)
- Pam: https://nuwanshan.github.io/lift/pam/ (iPhone: Safari → Share → Add to Home Screen)

Logs are stored on each phone only; export a backup from Progress.
Shipping an update: bump VERSION in app.js, sw.js and pam/sw.js.
